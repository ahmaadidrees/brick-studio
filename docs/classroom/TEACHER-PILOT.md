# First classroom pilot

The classroom release is live at https://virtual-legos.vercel.app. Release identities are recorded in PRODUCTION-RELEASE.json.

1. Open Brick Studio, then My Class and Teacher sign in. Choose Continue with Google and select your existing teacher account. Email/password remains available as an alternative.
2. Create a class. Give students its enrollment code. Students choose Join a class, enter the code, and create their username, password, and roster name. The roster name helps you identify students; classmates see usernames.
3. Start with two students. Have each save a build through My Worlds, sign out, sign back in, and reopen it. On shared devices, always use Sign out / switch account between students.
4. Create a shared world from the current build in My Class. Choose Whole class, or Assigned group and add students using World controls. Students find it in My Class and choose Join world; no invitation link is needed.
5. Have both students place different bricks, then leave and rejoin. Confirm both contributions remain. Before expanding to the full class, try the same flow on a school Chromebook.

## Everyday controls

- Students → Manage: change username or roster name. Set or generate a temporary password when needed; the student must choose a new password after signing in. Leave it empty to retain the current password.
- Suspend classroom access / Reactivate access: control an individual student's access without deleting their build data.
- Close enrollment: stop new accounts joining. Existing accounts remain. New enrollment code replaces the signup code; the returning sign-in code remains available.
- Close collaboration: end student access to shared worlds while preserving the work. The teacher can still review shared worlds.
- World controls → Remove from group: remove a student's access while keeping their contributions.
- Restore world: choose an earlier checkpoint when recovery is needed. Restoring first preserves a checkpoint of the current version.

Guest building, exploration, local drafts, import/export, and **Build together by invitation link** are available without signing in. Use Build together to create a temporary guest room and share its invite link; students choose a builder name. Export the build for long-term retention. An account is required for My Class collaboration and durable My Worlds saving. See GUEST-HOTFIX-2026-09-10.md for the restored guest flow and verification.
