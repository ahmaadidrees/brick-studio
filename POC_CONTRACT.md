# Rover Island MVP contract

## Promise

A student finishes a rover, gives it a short program, tests and resets it, then enters the same world and rides the same machine to deliver a battery to a lighthouse.

## Audience and session

- Grades 4–6
- Chrome and Chromebook first
- First success within eight minutes
- No login, download, or teacher setup

## Required proof

1. The student makes meaningful connections to a starter chassis.
2. The program changes the rover's behavior.
3. The color sensor reads from its physical position on the rover.
4. Reset recreates the same initial simulation state.
5. The avatar can board the student-built rover and complete the delivery.

## Included

- Original toy-like floating island and parts
- Data-driven parts and connection slots
- Easy Build snapping with visible feedback
- Two motor modules, controller, color sensor, seat, and battery
- Minimal block-style motor program
- Build, Code, Test, and Play modes
- Third-person avatar and seat interaction
- Mission guidance, sensor telemetry, audio feedback, and completion state

## Deliberately excluded

- Accounts, persistence, classrooms, and public sharing
- Multiplayer
- Blockly and Python
- AI features
- Large catalogs and advanced CAD tools
- Mobile-first controls
- Flexible components and complex mechanical constraints

## Acceptance signals

- A new player can finish the rover without external instructions.
- First movement occurs within five minutes.
- A player can identify why the rover did or did not stop on red.
- The complete Build → Code → Test → Play loop has no dead ends.
- The scene remains responsive on a typical school Chromebook profile.
