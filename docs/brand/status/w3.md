## Requests for lead

1. `src/ui/Field.tsx`: `required` appends a visible " *" inside the `<label>`, which changes the accessible label text
   ("Password *"), so `getByLabelText('Password')` and W8 locators would miss. W3 works around it with `fields.tsx`
   (`TextInput` puts native `required` on the input only). Suggest rendering the marker outside the label element or
   adding a `requiredMark={false}` prop; W3 would then switch to `TextField`.
2. `src/ui/Button.tsx`: no anchor rendering. `TeacherGoogleCallback` uses `<a class="ui-button ui-button-primary
   ui-button-md">` for its two links. Suggest `as="a"` / `href` support so links stop depending on class names.
3. `src/ui/ui.css`: `.ui-segmented-option` is 38px and `.ui-button-sm` 36px on every pointer type. W3 lifts them to
   44px inside `.classroom-sheet` under `(pointer: coarse)`; consider doing that in the primitive so every lane gets D7.
4. `src/ui`: no Select primitive; W3 styles a native `<select class="ui-input">` in `fields.tsx` (`SelectInput`).
5. `client.ts` (lead-owned, not changed): the `ClassroomError` message for an origin mismatch still says "stay in
   Brick Studio" and the callback says "not enabled as a Brick Studio teacher"; `googleTeacher.test.ts` asserts the
   first. Rename to `BRAND_NAME` when convenient (W3 will update the string assertion).
6. W8 locators: see "Final accessible names" above ("Sign-in code" → "Class sign-in code"; nav buttons are radios).
