## Requests for lead

- **W4 (`BrickStudioApp` `resizeSelection`)** — the resize sheet only shows the generic "does not fit" text because
  the callback returns `false` and toasts the real reason. `ResizeBrickSheet.onApply` accepts
  `boolean | { ok: true } | { ok: false; message }`; suggested change in `resizeSelection`:
  `if (!result.ok) { useBrickStore.setState({ toast: result.message }); return { ok: false, message: result.message } }`
  (the `onResizeSelection` prop type of the editor body widens to `ResizeApplyResult`; `import type { ResizeApplyResult }
  from './customParts/ResizeBrickSheet'`).
- **W4 (`BrickStudioApp` `applyContentSelection`)** — same for the plate shrink: return
  `{ ok: false, message: resized.error.message }` next to the existing toast so the scene sheet shows its in-sheet
  rejection (it currently just stays open). `WorldAndCharacterSheet.onApply` type: `void | boolean | { ok: false;
  message }`.
- **W4 (`BrickDrawerSheet` cleanup, compact layouts)** — its unmount cleanup calls `restoreTo?.focus()` even when
  another modal dialog already holds focus (Create a brick opens as the drawer closes). Suggested guard:
  `if (!document.activeElement?.closest('[role="dialog"][aria-modal="true"]')) restoreTo?.focus()`. CreateBrickSheet
  works around it (reclaims focus, restores to the drawer button on close) but the guard belongs in the drawer.
- **W1 (`src/ui/Sheet.tsx`)** — optional hardening for the same case: re-check focus in a passive effect after open and
  fall back to a still-connected element on close instead of leaving focus on `<body>`.
- **W1 (`SegmentedControl`)** — not adopted for the 64/96/128 plate choice because it has no `aria-describedby`
  passthrough (the group needs the "Your creation stays centered." hint association) and its options are 38px tall on
  touch. If those two are added, the plate buttons in `WorldAndCharacterSheet.tsx` can switch to it.
- **W4 (label)** — board 10 says "Create brick"; the primary stays "Create and place" because
  `BrickStudioApp.test.tsx` and the toast copy ("… is ready to place") depend on it. Rename together if wanted.
- **W7** — scene thumbnails at 800×500 and 400×250 (16:10) under the exact paths above; no W5 change needed when
  they land. Classic Studio should stay neutral.
- **W8** — `scripts/qa/verify-character-customizer.mjs` scrolls `.world-character-sheet-body`; that class still
  exists (an inner wrapper) but the scroll container is now `.ui-sheet-body`. Prefer
  `page.locator('[role="dialog"] .ui-sheet-body')` for scroll resets.
