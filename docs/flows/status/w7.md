## Real vs mocked (the one thing to read)

The local `wrangler dev` Worker answers **503 `classroom_unavailable`** for every classroom route without the three
Supabase secrets, and classroom live rooms need `CLASSROOM_TICKET_SECRET` too. So:

- **Real Worker (8797, this tree, local DOs):** guest live rooms — two-client multiplayer 9/9, the `/live/<id>` gate.
- **QA mock (8798, `scripts/qa/lib/classroom-mock-server.mjs`):** every `/classroom/*` call. The browser side is the
  real pages, real `ClassroomClient`, real sessionStorage session, real `useClassroomSession`; only the HTTP peer is
  synthetic. It mirrors `docs/classroom/API.md` + the W1 handlers including 409 `username_taken` + suggestions,
  `class_code_required`, `sharing_disabled`, `world_hidden`, `read_only`, `world_limit`, `revision_conflict` and
  `cf6fad9`'s suspended-owner 404. `buildingNow` is always null on the mock.
- **Blocked (3 e2e steps):** viewer read-only HUD, classmate Join + place, eject on unshare. Their access rules are
  proven at the API (`canEdit`, `world_hidden`, 404 after unshare). `flows-e2e.mjs` runs unchanged against a real
  Worker (`CLASSROOM_API`/`LIVE_API` + the two `VITE_*` URLs); one staging run closes them.
