# Runtime character portraits

These 400 x 400 WebP portraits were captured from the application's real
`CharacterPreview` canvas on 2026-09-14, using Chrome and default character
preferences. They depict the existing `classic`, `toy-figure`, and `cc0-hero`
models, with the 3D Toy Room preview stage introduced in commit `e10c857`.

The isolated local browser paused Idle animation and hid all UI outside the
preview before capture. Images were encoded to WebP at quality 88, without
compositing or generated artwork. Each card is a default portrait; the adjacent
live preview shows the user's actual draft colors and appearance.

The models and their existing licenses/provenance are unchanged. In particular,
Robot Hero retains the source documented in
`src/brick/characters/cc0-hero/ASSET_PROVENANCE.md`.
