## AppHeader props (exact)

Common: `session?: ClassroomSessionState` (override for previews/tests; otherwise the hook), `className?`,
`accountMenuDefaultOpen?`, `onKeyDown?`, `id?`.

- `variant="landing"`: `navigation?: ReactNode`.
- `variant="page"`: `title?: string`, `actions?: ReactNode`.
- `variant="editor"`:
  `onNewBuild?`, `onImportProject?(file)`, `onExportProject?`, `onPublishWorld?` (accepted, not rendered — same as
  today), `onOpenSettings?` (⋯ menu), `onOpenHelp` (required), `worldTitle?`, `onRenameWorld?(title): Promise<void>`,
  `saveStatus: { source: SaveStatusSource; detail?: string }`, `onOpenWorldSetup(tab?)`, `onStartLiveWorld?`,
  `livePolicy?: HeaderLivePolicy` (`connection, isOwner, roomTitle?, peopleCount?, onOpenPeople?, pendingOperations?,
  sessionReplaced?` — `BrickStudioLivePolicy` satisfies it structurally), `mode: 'build'|'explore'`,
  `onRequestMode(mode)`, `canExplore: boolean`, `exploreReason?`, `onSaveToAccount?`, `onOpenMyWorlds?` /
  `onOpenMyClass?` (accepted for parity; the account menu links to `/worlds` and `/class` instead), `onGoHome`.
