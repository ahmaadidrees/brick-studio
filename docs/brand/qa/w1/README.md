## Automated checks (script output)

  widens the layout viewport when any element's intrinsic width exceeds the screen; the gallery is now free of that).
- Escape closes the sheet and focus returns to "Open settings sheet" at both sizes.
- 200% zoom emulation (683×384 CSS px at 2×): no horizontal overflow; the sheet footer stays fully inside the viewport.
- Tab order through the header: Brickgineers Home → Desk Castle → Scene → Character → People → Settings → Explore →
  (demo controls); every stop shows `outline: solid 3px rgb(53, 101, 191)` (`--focus`).

- `prefers-reduced-motion: reduce`: sheet and backdrop animation-duration 1e-05s (kill switch), spinner `animation-name: none`.

## Contrast (WCAG 2.x, sRGB relative luminance)

Rule of thumb encoded in the tokens: ink text on warm white / white / butter; white text only on `--primary-strong`,
`--danger`, `--success`; the brand cornflower and coral are surface, border and illustration colors. Measured:

| Use | Foreground | Background | Ratio | AA |
|---|---|---|---|---|
| Body text | --text #263C51 | --bg #F8F4EB | 10.35:1 | pass (4.5:1) |
| Body text on cards | --text #263C51 | --surface #FFFFFF | 11.37:1 | pass (4.5:1) |
| Muted text | --text-muted #4F6478 | --bg #F8F4EB | 5.58:1 | pass (4.5:1) |
| Muted text on cards | --text-muted #4F6478 | --surface #FFFFFF | 6.13:1 | pass (4.5:1) |
| Primary button label | --primary-contrast #FFFFFF | --primary-strong #3565BF | 5.58:1 | pass (4.5:1) |
| Primary button hover | --primary-contrast #FFFFFF | #2E59AC | 6.69:1 | pass (4.5:1) |
| Link / quiet hover text | --primary-strong #3565BF | --surface #FFFFFF | 5.58:1 | pass (4.5:1) |
| Link on warm white | --primary-strong #3565BF | --bg #F8F4EB | 5.08:1 | pass (4.5:1) |
| Danger button label | --primary-contrast #FFFFFF | --danger #C9463A | 4.75:1 | pass (4.5:1) |
| Danger text (errors) | --danger-text #B0432E | --surface #FFFFFF | 5.69:1 | pass (4.5:1) |
| Danger text on soft | --danger-text #B0432E | --danger-soft #FBE4E0 | 4.68:1 | pass (4.5:1) |

| Warning pill text | --warning-text #8A5A00 | --warning-soft #FDF1D3 | 5.28:1 | pass (4.5:1) |
| Busy pill text | --primary-strong #3565BF | --primary-soft #E8EFFB | 4.83:1 | pass (4.5:1) |
| Ink on butter (illustration labels) | --text #263C51 | --warning #F3CA74 | 7.31:1 | pass (4.5:1) |
| Ink on coral (illustration labels) | --text #263C51 | --accent #F17861 | 4.11:1 | large text only (3:1) |
| Focus ring vs warm white | --focus #3565BF | --bg #F8F4EB | 5.08:1 | pass (3:1 non-text) |
| Focus ring vs card | --focus #3565BF | --surface #FFFFFF | 5.58:1 | pass (3:1 non-text) |
| Input border | --border-strong #B9C2CC | --surface #FFFFFF | 1.80:1 | fail |
| Brand blue as text (NOT allowed) | --primary #5888DA | --surface #FFFFFF | 3.53:1 | large text only (3:1) |
| White on brand blue (NOT allowed for text) | #FFFFFF | --primary #5888DA | 3.53:1 | large text only (3:1) |
| White on coral (NOT allowed for text) | #FFFFFF | --accent #F17861 | 2.76:1 | fail |

Notes:

- `--primary #5888DA` is 3.53:1 on white: fine for icons, borders, selection tint and large display text, never for
  body text or white-on-blue buttons. Primary buttons and links use `--primary-strong #3565BF` (5.58:1 on white,
  5.08:1 on `--bg`).
- Coral `#F17861` never carries white text (2.76:1). Destructive buttons use `--danger #C9463A` (4.75:1) and error
  text uses `--danger-text #B0432E` (5.69:1 on white).
- Input borders (`--border-strong`, 1.80:1) are below the 3:1 non-text target on their own; the field is also identified
  by its always-visible label and by the 3px focus ring, and the hover state raises the border to `--primary`.
  Lanes that need a stronger idle border can use `--border-strong` → `--text-muted` locally.
- Ink on coral reaches 4.11:1: use it only for large display text on illustration, not for body copy.

## Manual checks

  (favicon) through 96px; mono and outline variants use `currentColor`.
