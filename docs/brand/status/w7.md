### Media pipeline

- `scripts/art/media-seed.mjs` — the seed castle (59 catalog bricks, brand colours, 64 plate) shared by every capture.
- `scripts/art/media-capture.mjs` — Playwright + Chrome against a running dev server; restores the seed through the real
  store, hides everything but the canvas with `visibility`, places the build camera (hero: `2,6,15 → 2,5,-9`, fov 70
  chosen from five framing trials so lamp, castle and books share the frame like the board; scene cards:
  `-8,8,22 → 1,2.5,-4`, fov 50), and for characters sets the preference through `saveCharacterPreferences`, reloads,
  enters Explore and orbits to the avatar's face. Writes masters + `capture-report.json`.
- `scripts/art/media-optimize.mjs` (new) — `sharp` (already in `node_modules`) Lanczos resize; WebP via sharp and AVIF
  via `/opt/homebrew/bin/avifenc`, each walking down in quality until the file meets its cap; 256-colour palette PNG
  fallbacks; rewrites `manifest.json` (measured width/height/bytes/sha256, quality, budgets, provenance: commit,
  capture timestamp, seed, encoder versions) and `MEDIA.md` (byte table). No new npm dependencies.
- `public/brand/media/`: `hero-{1600,1200,800}`, `scene-{toy-room,brick-valley,sky-island,classic}-{800,400}`,
  `character-{pip,fern,nova,toy-figure}-400` × `{avif,webp,png}` = 45 files. `cc0-hero` excluded.

Byte sizes (measured, `public/brand/media/MEDIA.md` has the full 45-row table):

| Budget | Cap | AVIF | WebP |
|---|---:|---:|---:|
| Hero delivered (`hero-1600`) | 250 KB | 54.4 KB | 88.2 KB |
| Initial set (`hero-1600` + 4 × `scene-*-800` + 4 × `character-*-400`) | 600 KB | 164.6 KB | 244.8 KB |

Every file met its cap at the first (highest) quality step: AVIF q62, WebP q84. PNG fallbacks are 256-colour palette,
19–154 KB. Whole folder 1.8 MB on disk. Provenance recorded in `manifest.json` (commit `0aa3f0b` = the room state the
masters were rendered from; the scripts landed in the following commit).
