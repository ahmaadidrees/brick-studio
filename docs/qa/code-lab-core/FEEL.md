# Code Lab: Hero feel comparison (step 5)

Generated by `npx vitest run src/platformer/lab/feel` (`src/platformer/lab/feel/feel.test.ts`). Do not edit by hand.

- **Old**: `platformer-core` `DEFAULT_FEEL` at 60 frames/s, measured through its test harness on flat levels built in code.
- **New**: Jumper stand-in (the starter's Jumper, not the Hero). It exists only to prove the plumbing: it has no momentum, run, variable jump height, coyote time or buffer, so it is expected to fail the tolerances. Plug the Hero in through `feel/target.ts`.
- **Result**: 0 of 25 judged metrics inside tolerance.

Same input scripts for both (per 60 Hz frame; the Code Lab runner ORs each pair of frames into one 30 tick/s tick).
Positions are measured in pixels (1 Code Lab step = 1 pixel), y up. Times are in ms. Diff = new minus old.
